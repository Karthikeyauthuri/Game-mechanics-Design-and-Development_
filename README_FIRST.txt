3D CAR DRIVING SIMULATOR - quick start
1. Install Unity Hub, then install Unity 2022.3 LTS (any 2022.3.x).
2. Extract this ZIP (right-click > Extract All). Keep the folder path short, e.g. C:\Games\Car3DDrivingSimulator
3. Unity Hub > Add > Add project from disk > select the Car3DDrivingSimulator folder.
   If Hub says the editor version is missing, choose your installed 2022.3.x version and open.
4. First open takes a few minutes (it imports assets).
5. In the Project window open Assets/Scenes/MainScene, then press Play.
6. Controls: W/S or Up/Down, A/D or Left/Right, Space = brake, Esc/P = pause. On-screen buttons also work.
7. Build: File > Build Settings > pick platform > Build (MainScene is already in the list).
